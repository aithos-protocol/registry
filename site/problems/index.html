Problem types

Every refusal this registry makes is an RFC 9457 document carrying one of these codes, and its type member links to the page below.

Two refusals carry no code and must be handled by status alone: a 429 from the gateway's own throughput limit, and a 403 from the edge for a method a cached read path does not serve.

  • JSON_INVALID · 400 · Invalid JSON
  • PRIVATE_KEY_SUBMITTED · 400 · Private key material submitted
  • NOT_AUTHORIZED_KEY · 403 · Not signed by an authorized key
  • NOT_FOUND · 404 · Not found
  • AGENT_ID_MISMATCH · 409 · Identifier does not match the signing key
  • VERSION_NOT_INCREASING · 409 · Card version does not move forward
  • WITHDRAWN · 410 · Entry was withdrawn
  • PRECONDITION_FAILED · 412 · Precondition failed
  • CARD_TOO_LARGE · 413 · Agent Card is too large
  • CARD_INVALID · 422 · Agent Card is invalid
  • PRESENCE_INVALID · 422 · Field presence rules were not applied
  • SIGNATURE_INVALID · 422 · Signature is invalid
  • KID_NOT_THUMBPRINT · 422 · Key identifier is not the key's thumbprint
  • ALG_NOT_ALLOWED · 422 · Algorithm is not allowed
  • UNUSED_KEY · 422 · A submitted key signs nothing
  • TOO_MANY_KEYS · 422 · Too many keys submitted
  • DUPLICATE_KEY · 422 · The same key was submitted twice
  • KEY_INVALID · 422 · A submitted key is malformed
  • UNPROVEN_KEY · 422 · A signing key did not ask for this publication
  • CURSOR_INVALID · 400 · Pagination cursor is not valid
  • CONFLICT · 409 · The agent changed concurrently
  • METHOD_NOT_ALLOWED · 405 · Method not allowed
  • INTERNAL · 500 · The registry could not complete this request
  • RATE_LIMITED · 429 · Too many requests
  • FORBIDDEN · 403 · Not reachable this way
  • REQUEST_REFUSED · 400 · Request refused
  • DOMAIN_SYNTAX_INVALID · 422 · Domain syntax is invalid
  • DOMAIN_IS_PUBLIC_SUFFIX · 422 · Domain is a public suffix
  • DOMAINS_NOT_CANONICAL · 422 · Domain list is not sorted
  • TOO_MANY_DOMAINS · 422 · Too many domains
  • CERTIFICATION_NOT_INCREASING · 409 · Certification does not move forward
  • DNS_RECORD_ABSENT · 422 · DNS record absent
  • DNS_UNRESOLVED · 422 · DNS resolution failed
Normative in SPEC.md §9 and DOMAIN-CERTIFICATION.md §11. The HTTP surface is described by openapi.json.
